# deep-learning-case-study# 

This repository contains implementations of various Deep Learning and NLP experiments using RNN, LSTM, GRU, Seq2Seq, Attention Mechanism, BERT, VAE, GAN, and GCN models.

---

## 📚 Lab Experiments

### 🔹 Lab 4: Compare RNN vs LSTM vs GRU Performance
Implemented and compared:
- Recurrent Neural Network (RNN)
- Long Short-Term Memory (LSTM)
- Gated Recurrent Unit (GRU)

Tasks performed:
- Model training
- Accuracy comparison
- Loss visualization
- Performance evaluation

---

### 🔹 Lab 5: LSTM for Text Classification & Seq2Seq
Implemented:
- LSTM-based Text Classification
- Sequence-to-Sequence (Seq2Seq) Model

Features:
- Tokenization & preprocessing
- Embedding layers
- Encoder-Decoder architecture
- Training & evaluation

---

### 🔹 Lab 6: Attention Heatmaps in Seq2Seq
Implemented:
- Attention mechanism in Seq2Seq models
- Visualization of attention weights

Features:
- Encoder-Decoder with Attention
- Heatmap visualization
- Sequence alignment analysis

---

### 🔹 Lab 7: Fine-Tuning BERT for QA / Sentiment Analysis
Implemented:
- BERT fine-tuning using HuggingFace Transformers

Tasks:
- Question Answering
- Sentiment Analysis

Features:
- Pretrained BERT model
- Tokenization
- Fine-tuning
- Evaluation metrics

---

### 🔹 Lab 8: VAE, GAN, and GCN
Implemented:
- Variational Autoencoder (VAE)
- Generative Adversarial Network (GAN)
- Graph Convolutional Network (GCN)

Features:
- Latent space visualization
- Image synthesis using GAN
- Citation graph learning using GCN
